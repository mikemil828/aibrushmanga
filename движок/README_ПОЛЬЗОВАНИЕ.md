# «Кисть» — первый час

Движок масляной живописи: картина выходит из волосков кисти, краски, нажима и рельефа. Здесь — цикл, все инструменты и главное; подробно — `СПРАВОЧНИК.md` (`python -m кисть.справка <слово>`), цикл и карта подробно — там, «Работа с движком подробно».

**До первого мазка** — совет в корневом `README.md` поставки («Advice»): не строй автомат, который пишет картину вместо тебя. Пишешь автомат или полуавтомат всё равно — пусть кладёт ходы инструментами движка (раздел «Свой цикл»).

## 1. Рабочий цикл

Пиши **программой на Python**, куском за куском: положил, посмотрел, замерил, переписал.

1. **До кладки:** `нагрузка_для(кисть, покрытие=0.9)`, `план_покрытия`; пробой — `х.проба`, `х.перебор`.
2. **Кладка:** `х.снимок()`, `х.пометка('…', этап=…, объект=…)`, цикл мазков. Ответ `о = х.мазок(…)`: `о.цвет`, `о.закрыто`, `о.просветы`, `о.разрывы`, `о.край`, `о.осталось`, `print(о)` — читай у первых мазков пачки.
3. **Кроп:** `х.взгляд(область, 2, рядом=образец, путь='кроп.png')` — открой глазами; лист — `х.виды(…, цель=образец)`.
4. **Замер:** `х.разность`, `х.просвет`, `х.манера(область, образец=…)` — число подтверждает глаз.
5. **Зеркало после серии:** `print(х.однообразие())`; строки `подсказка: …` не глуши `grep`.
6. **Правка:** `х.откатить(снимок)` и перепиши кусок; попытки разом — `х.варианты`, `х.взять`.

Журнал пишет холст сам (`Холст(…, журнал='лист.jsonl')`), строк руками не сочиняй. Из `примеры/цикл.py`:

```python
снимок = х.снимок()                                  # до куска: откат вернёт холст и журнал
о = писать_лист(х, м, НАГРУЗКА, п['разброс'], п['ровно'])     # ответы мазков: что вышло у каждого хода
```

## Свой цикл — инструментами движка

Своим кодом → движком:

- цвет формулой в точке → замесы `х.палитра({…})`, черновик `х.палитра_с`, мазок именем;
- полная кисть каждый ход, свой счётчик краски → `к.набрать(цвет, количество)`, ходы без цвета, `к.хватит(холст=х)`;
- прямые точки → `жест(опоры, ширина, 'отрыв')` (и `'подъём'`, `'остановка'`, `'смахивание'`), `тычок`, `нажим_вдоль`;
- маска и сетка с дрожанием → после серии `х.однообразие(объект=…)`, `х.регулярность`;
- перезапуск этапа ради числа → `х.перебор`, `х.варианты`;
- высохшее «не правится» → `х.размочить`, `х.прижать`, `мастихин`.

## 2. Полный пример: лист проб на чистом холсте

`примеры/цикл.py` — пробник, заливка, шкала нажима, сырое в сырое, край мягкой; что меряет — справочник, «Полный пример»:


## 3. Подключить

Python 3, `numpy`, `scipy`, `Pillow`. `import sys; sys.path.insert(0, '<путь>/движок')`, `from кисть import Холст, Кисть, Краска, жест`. Px, y вниз, физика на 8 px/мм.

## 4. Главное о кисти

- **Слой:** мазок мешается только с сырой своего слоя. Время само не идёт: сушит `х.подсушить`.
- **Нагрузка — толщина плёнки кисти 40 px:** у узкой та же нагрузка тоньше, ход может лечь невидимым — бери `нагрузка_для`. Ходы по сырому складывают толщину: 0,4–0,6 на тысячах ходов — слой больше 1 мм; толщина — в `х.виды`.
- **Кисть** помнит грязь до `к.вытереть()`, краску считает после `к.набрать(цвет, количество)`.
- **Этап:** `х.сохранить('этап4.npz')`, затем `Холст.загрузить('этап4.npz', журнал='лист.jsonl')`. Палитра — из `.npz`, какой была: правил замесы — снова `х.палитра({…})`, иначе `НетЗамеса`.
- **Повтор:** `python -m кисть.повтор лист.jsonl --out лист.png`, после обрыва или правки — `--resume`. Подробно — «Главное о кисти подробно».

## 5. Неожиданное в движке

Признак — словом в справочнике, «Неожиданное в движке»: Грунт светит в бороздах · вуаль не видна · лессировка светлит · тон рядами втрое плотнее · лоскуты спада · серое пятно после растушёвки · рябь от `разброс_тона` · штампы одной плотности · крапины чужого тона · высохшее не правится · `ПустойМазок` (и удар за краем ближе ширины кисти) · `MemoryError` · `нет поля разброс_тонa` · `нет поля lvel` · своя запись журнала · ошибки `варианты` и `взять`.

Не движок, а письмо (кропы без прищура, зеркало против пустоты, вслепую, дыры глазом, черновик и пробник вручную) — «Ошибки письма при верной работе движка».
